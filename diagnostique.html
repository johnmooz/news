Les tests Internet n'ont pas pu joindre l'extérieur. Si vous voyez cette page dans Claude, c'est normal : les requêtes externes y sont bloquées. Téléchargez le fichier diagnostic.html et ouvrez-le directement dans votre navigateur pour les tests IP, DNS, latence et débit. Sinon, votre connexion Internet a probablement un problème.

Un navigateur ne peut pas lire directement les pilotes Windows/macOS (Wi-Fi, chipset, imprimante…). Cette page détecte les symptômes visibles depuis le navigateur : pilote graphique absent ou en rendu logiciel, périphériques audio/vidéo non détectés, connectivité, DNS, IP, latence, horloge système.
