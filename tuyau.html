Plombier

Raccordez l'arrivée d'eau à l'évacuation : tournez les tuyaux, ouvrez les robinets et orientez les vannes trois voies jusqu'à ce que l'eau circule d'un bout à l'autre.

Choisissez un niveau

100 tuyaux
  • Mode Tourner : touchez un tuyau (ou un robinet) pour le faire pivoter d'un quart de tour.
  • Mode Robinets : touchez un robinet pour l'ouvrir (poignée verte) ou le fermer (poignée rouge).
  • Les tuyaux sous pression deviennent bleus ; les gouttes signalent une fuite.
  • Sur les grands niveaux, faites défiler le plateau avec l'ascenseur à droite.
