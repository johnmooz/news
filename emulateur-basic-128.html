PRÊT
TO8Cliquez sur l'écran pour taper · Tab complète · Échap = BREAK
Tab = compléter
Synchronisé avec la mémoire
Complétion automatique : tapez le début d'un mot-clé, puis Tab (ou ↑/↓ puis Entrée, ou touchez la suggestion). Tab passe ensuite d'un paramètre à l'autre. Entrée numérote la ligne suivante (+10). Les lignes tapées sur l'écran apparaissent ici.
Étiquette
FichierTaille
Chaque lecteur (0 à 3) est une disquette 3½ FAT12 de 1 474 560 octets (2 880 secteurs). L'export produit une image .IMG standard (dans un .zip), lisible par les émulateurs et montable sur PC. L'import accepte .img, .zip, .bas et .txt. Les disquettes restent dans ce navigateur : exportez-les pour les garder.

Mode direct

Tapez une ligne précédée d'un numéro pour l'ajouter au programme (un numéro seul l'efface). Sans numéro, la commande s'exécute immédiatement. ↑/↓ rappellent les commandes précédentes, Échap ou Ctrl+C interrompt.

RUN [n | "F"]
exécute (depuis la ligne n ou le fichier F)
LIST [a-b]
affiche le programme
NEW · CONT
efface · reprend après BREAK/STOP
EDIT n
rappelle la ligne n pour la modifier
DELETE a-b
supprime des lignes
RENUM [d[,a[,p]]]
renumérote (GOTO/GOSUB suivis)
TRON · TROFF
trace des numéros de ligne
